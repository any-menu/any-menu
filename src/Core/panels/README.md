- MulPanel

- shared/
  - (otherFolders)
    - MulPanel/

概念

将UI按大小和功能复杂度分为三个级别：
- 控件 (通常是一个单一的功能元素)
- 子面板 (即一个UI模块，可包含多个控件)
- 多面板集 (相当于是窗口，可包含多个子面板。通常可动态调整内部子面板的大小、显示/隐藏/增添哪些子面板)

层级

- 面板容器 (同一个窗口只会存在一个)
  多窗口情况下 (使用拆分功能) 会存在多个，但只有一个是主面板
  - 子面板 (同一个窗口中的多个功能区域)
    - (可选) 面板项 (一般是按钮、功能按键)

## 子面板布局设计准则

对于单行的游离按钮元素和小元素，推荐高度为 30 px
(目前设计的子元素符合该规范: search, pin, 单行的toolbar 均是高 30px)

对于成组为多行的游离按钮元素和小元素，推荐高度为 26-28 px
(目前设计的子元素符合该规范: toolbar 中的项，多级菜单中的项)
