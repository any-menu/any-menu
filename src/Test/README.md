# 程序测试

目前主要为人工测试，并未有单元测试和e2e测试。这里也仅列举一些主要的测试项。

该项目测试起来比较繁琐和麻烦，有些比较难以自动化测试。

每个版本发布前需要人工测试以下项目。

## 测试内容 (完善中)

环境:

- 需对 Browser、Obsidian、App 均进行一遍测试
- App 以后可能需要多平台测试，但目前仅开发、维护、测试 Windows 平台

测试项:

- 工具栏测试
  - 测试 color 和 background 脚本。
    自动唤出并使用他们、手动唤出并使用他们、面板置于置顶状态并使用他们。均至少测试两遍
- 多级菜单测试
  - 测试 adQuote 菜单。

以上测试项可覆盖主要插件 api:

- 选中文本环境检测
- 输出文本
